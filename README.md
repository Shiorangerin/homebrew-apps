# Orangerin Apps

## How do I install these formulae?

`brew install orangerin/apps/<formula>`

Or `brew tap orangerin/apps` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "orangerin/apps"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
